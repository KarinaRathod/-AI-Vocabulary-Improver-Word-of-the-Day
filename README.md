
# 📚✨ AI Vocabulary Improver & Word of the Day

An AI-powered vocabulary enhancement app that helps users improve their English by generating better sentence alternatives, learning new words daily, and tracking progress.

---

## 🚀 Features

- 📅 Word of the Day with meaning, examples, and synonyms
- 🧠 AI-powered sentence improvement
- 🎯 Level-based vocabulary learning (Beginner → Advanced)
- 💾 Save and review learned words
- 📊 Progress tracking (optional enhancement)
- ⚡ Clean UI using Streamlit

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API
- Matplotlib (for visualization)
- Session State (memory)

---

## ⚙️ Setup Instructions

### 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/ai-vocabulary-improver.git
cd ai-vocabulary-improver
````

---

### 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

### 3️⃣ Setup Environment Variables

Create a `.env` file:

```env
GOOGLE_API_KEY=your_gemini_api_key
```

Get your API key from:
[https://makersuite.google.com/app/apikey](https://makersuite.google.com/app/apikey)

---

### 4️⃣ Run the App

```bash
streamlit run app.py
```

---

## 🧪 How It Works

1. Generate a **Word of the Day**
2. Improve your own sentences using AI
3. Learn words based on your level
4. Save useful words for revision
